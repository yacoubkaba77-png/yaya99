# Contributing to yaya99

Thank you for your interest in contributing! We appreciate your help.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/yaya99.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`

## Development Workflow

### Running the Project

```bash
npm run dev
```

### Running Tests

```bash
npm test
```

### Linting Code

```bash
npm run lint
```

### Building

```bash
npm run build
```

## Code Style

- Use 2-space indentation
- Use single quotes for strings
- Always add semicolons
- Use meaningful variable names
- Add comments for complex logic

## Submitting Changes

1. Make your changes
2. Run tests to ensure everything works: `npm test`
3. Lint your code: `npm run lint`
4. Commit with clear messages: `git commit -m 'feat: description of changes'`
5. Push to your fork: `git push origin feature/your-feature-name`
6. Open a Pull Request with a clear title and description

## Pull Request Process

- Ensure all tests pass
- Update documentation if needed
- Add a clear description of what your PR does
- Reference any related issues

## Commit Message Format

Use conventional commits:
- `feat: add new feature`
- `fix: fix a bug`
- `docs: update documentation`
- `test: add tests`
- `refactor: refactor code`
- `style: format code`
- `chore: update dependencies`

## Questions?

Feel free to open an issue or reach out to the maintainers.

Happy coding! 🚀
